# 🔐 Simple Login System

A simple Login and Signup web application built using **HTML, CSS, JavaScript, Node.js, and Express.js**.

## ✨ Features

- User Login
- User Signup
- Home Page
- Responsive Design
- Express.js Routing

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## 📂 Project Structure

```
project/
├── css/
├── js/
├── views/
├── server.js
├── package.json
└── READE.md
```

## 🚀 Run the Project

```bash
npm install
node server.js
```

Open your browser:

```
http://localhost:3000
```
